# granaris-site

Page de présentation de **Granaris**, logiciel Windows de gestion de silo à céréales.

Publiée par GitHub Pages sur https://granaris.agristock.fr (fichier `CNAME`).

- `index.html` : la page (HTML + CSS + un peu de JavaScript, sans outil de construction)
- `images/` : captures d'écran prises sur la base de démonstration (données fictives)

Les installateurs et les mises à jour du logiciel sont publiés dans le dépôt
[granaris/granaris-releases](https://github.com/granaris/granaris-releases).
